Data handling

History and content diagnostics are off. Audio and results are temporary. Context collection and automatic raw fallback are unavailable; external delivery requires review and explicit copy.

A clear local boundary

No accounts, remote assets, automatic downloads, updates, telemetry, or cloud fallback. This build makes no inference HTTP requests, including loopback requests. Native inference runs as a local child process.

Renderer and Node request guards are defense in depth. They are not an OS firewall. Use the documented process-level blocking and observation procedure to verify a particular native runtime.

Audio uses temporary WAV files in a restricted folder and is deleted after processing, cancellation, and recoverable startup cleanup. Deletion is not secure erasure. Results live in memory. Explicitly copied text remains on your clipboard; pasted text follows the receiving app's data handling.

Current adapter capabilities

Windows UI Automation can inspect supported fields and explicit selections; other adapters cannot. Capability failures require manual delivery. Automatic external insertion is disabled on every platform.
