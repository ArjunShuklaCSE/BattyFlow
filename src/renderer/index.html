Written as When you say Where

Separate spoken forms with commas. “Where” limits a word to one kind of app; code words also apply in terminals. If two words share a spoken form in the same place, BattyFlow leaves what you said untouched.

Polish optional

A small local language model that tidies punctuation and filler words, and powers the Command, Edit and Translate modes. If it would change your meaning, numbers or identifiers, your words are kept as spoken.

Import your own files

For machines without internet access, or models not listed here. Import a JSON manifest that points at the file and lists its SHA-256, size, license and languages. See the model guide.

Privacy

Audio and text never leave this computer. No account, no telemetry, no cloud fallback. The only network requests are model downloads you start yourself, from GitHub and Hugging Face.
